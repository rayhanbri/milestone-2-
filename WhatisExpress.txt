# What is Express.js?

Express.js is a lightweight and fast web framework for Node.js.
It helps developers build **web applications** and **REST APIs** easily using JavaScript or TypeScript.

Instead of writing everything manually with Node.js core modules, Express gives you ready-made tools and structure.

---

# Why Do We Use Express?

Without Express, creating a server in Node.js becomes more complex and repetitive.

### Using only Node.js

```js
const http = require("http");

const server = http.createServer((req, res) => {
  if (req.url === "/") {
    res.end("Home Page");
  }
});

server.listen(5000);
```

You manually handle:

* Routes
* Request parsing
* Responses
* Middleware logic
* Error handling

---

### Using Express

```js
const express = require("express");

const app = express();

app.get("/", (req, res) => {
  res.send("Home Page");
});

app.listen(5000, () => {
  console.log("Server running");
});
```

Much cleaner and easier.

---

# Main Reasons to Use Express

## 1. Easy Routing

Express makes route handling simple.

```js
app.get("/users", (req, res) => {
  res.send("All Users");
});
```

Different HTTP methods:

* GET
* POST
* PUT
* PATCH
* DELETE

---

## 2. Middleware Support

Middleware is one of Express’s biggest features.

Middleware functions run between request and response.

```js
app.use(express.json());
```

This middleware converts JSON request body into JavaScript object.

Example:

```json
{
  "name": "Rayhan"
}
```

becomes:

```js
req.body
```

---

## 3. Build REST APIs Easily

Express is widely used for backend API development.

Example:

```js
app.post("/users", (req, res) => {
  const user = req.body;

  res.json({
    success: true,
    data: user,
  });
});
```

---

## 4. Faster Development

Express reduces boilerplate code.

You can quickly build:

* Authentication systems
* CRUD applications
* Dashboards
* E-commerce backends
* Real-time apps

---

## 5. Huge Ecosystem

Express works easily with:

* MongoDB
* PostgreSQL
* Prisma
* JWT
* TypeScript
* Socket.io
* Multer
* Cors

# Key Concepts in Express

## App

```js
const app = express();
```

`app` controls the whole server.

---

## Route

```js
app.get("/about", (req, res) => {
  res.send("About Page");
});
```

Defines what happens on a URL.

---

## Request (`req`)

Contains client data.

```js
req.body
req.params
req.query
```

---

## Response (`res`)

Used to send data back.

```js
res.send()
res.json()
res.status()
```

---

# Real-World Example

Suppose you are building a blog website.

Frontend sends request:

```txt
GET /posts
```

Express receives it:

```js
app.get("/posts", (req, res) => {
  res.json(posts);
});
```

Then Express sends all posts to frontend.

# Common Interview Questions

## Basic Level

### Q1: What is Express.js?

Express is a minimal and flexible Node.js framework used to build web servers and APIs.

---

### Q2: Is Express a backend framework?

Yes. Express is used for backend/server-side development.

---

### Q3: What is middleware in Express?

Middleware is a function that executes during the request-response cycle.

---

## Intermediate Level

### Q4: Difference between Node.js and Express?

| Node.js             | Express            |
| ------------------- | ------------------ |
| Runtime environment | Framework          |
| Lower-level         | Higher-level       |
| More manual work    | Easier development |

---

### Q5: What does `express.json()` do?

It parses incoming JSON request bodies.

---

# Common Mistakes

## Forgetting middleware

Wrong:

```js
req.body // undefined
```

Because:

```js
app.use(express.json());
```

was missing.

---

## Not sending response

Wrong:

```js
app.get("/", (req, res) => {
  console.log("Hello");
});
```

Browser keeps loading forever because no response was sent.

---
